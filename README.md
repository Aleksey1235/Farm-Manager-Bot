# FARM Manager Bot v2.5

Новая версия бота отдела FARM с кнопочным управлением.

## Главное в v2.3

- Полностью кнопочное управление, без slash-команд.
- Живой список активных фармеров с таймерами.
- Контент ставит фарм на паузу; после возврата обязательно фото участия.
- При достижении настраиваемого дневного порога действует настраиваемая автосумма.
- Ниже порога руководство назначает сумму конкретному игроку прямо из его карточки отчёта.
- День без фарма не создаёт запрос на сумму.
- Настраиваемая скидка за каждый подтверждённый контент.
- Кнопка **«Мой день»**.
- Карточка игрока для руководства.
- Контроль забытых непрерывных фарм-сессий.
- Контроль оплат: оплатили / на проверке / не оплатили / не рассчитано.
- Сравнение текущей и прошлой недели.
- Автоматический еженедельный отчёт с настраиваемым расписанием.
- Состав FARM синхронизируется по роли; ушедшие участники сохраняются в исторической статистике.
- SQLite хранит состояния и историю между перезапусками.


## Что уже реализовано

- Только кнопки для действий участников и руководства.
- Постоянная панель FARM.
- Список активных игроков с обновляемыми таймерами.
- Чистое время фарма считается отдельными сегментами.
- «Уехать на контент» ставит фарм на паузу.
- «Вернуться с контента» возобновляет фарм, если он шёл до контента.
- После возвращения обязательно фото участия.
- Контент попадает руководству на подтверждение.
- Подтверждённый контент даёт настраиваемую скидку на недельный взнос.
- Если дневной фарм достиг настраиваемого порога (по умолчанию 4 часа) — настраиваемая автосумма (по умолчанию 100 000$).
- Если порог не достигнут — сумма не придумывается ботом: руководство назначает её конкретному игроку за конкретный день.
- Если сумма уже назначена, но игрок позже в этот же день дофармил до порога — ручная сумма заменяется автоматической.
- Недельная статистика и персональная статистика.
- Кнопка внесения недельного взноса, скрин оплаты и подтверждение руководством.
- Все финансовые параметры меняются через кнопочную админ-панель.
- SQLite WAL, foreign keys, сохранение активных состояний между перезапусками.
- Аудит ключевых действий.

## Важная настройка Discord Developer Portal

Для приёма фотографий нужно включить **MESSAGE CONTENT INTENT**.

Также включите **SERVER MEMBERS INTENT**.

## Установка Windows

1. Установите Python 3.11+.
2. Распакуйте проект.
3. Откройте CMD в папке проекта.
4. Выполните:

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

5. Скопируйте `.env.example` в `.env`.
6. Заполните ID и токен.
7. Запустите:

```bat
.venv\Scripts\python.exe main.py
```

## Каналы

- `PANEL_CHANNEL_ID` — основная постоянная панель отдела.
- `ADMIN_CHANNEL_ID` — панель руководства.
- `REPORT_CHANNEL_ID` — очередь отчётов и фото на проверку.
- `CONTENT_PROOF_CHANNEL_ID` — канал, куда участник после кнопки «Вернуться с контента» отправляет фотографию.
- `PAYMENT_PROOF_CHANNEL_ID` — канал для скринов итогового недельного взноса.

Рекомендация: канал фото сделать доступным FARM-составу, но запретить лишний чат правилами/правами.

## Роли

- `FARM_ROLE_ID` — роль участника FARM.
- `LEADERSHIP_ROLE_IDS` — ID руководящих ролей через запятую.

Пример:

```env
LEADERSHIP_ROLE_IDS=111111111111111111,222222222222222222
```

## Настройки по умолчанию

- Порог: 240 минут.
- Автосумма при достижении порога: 100000.
- Скидка за подтверждённый контент: 50000.
- Минимальный итоговый недельный взнос: 0.
- Напоминание о непрерывной сессии: 360 минут.
- Автоотчёт: воскресенье, 23:00 по TIMEZONE.

Все эти значения меняются из панели руководства.

## Логика контента

1. Участник нажимает «Уехать на контент».
2. Если он фармил — текущий фарм-сегмент закрывается, время перестаёт идти.
3. Статус становится «На контенте».
4. Участник нажимает «Вернуться с контента».
5. Если до контента он фармил — новый фарм-сегмент автоматически начинается.
6. Контент получает статус «Ожидает фото».
7. Участник отправляет картинку в `CONTENT_PROOF_CHANNEL_ID`.
8. Бот пересылает отчёт с картинкой руководству.
9. Руководство подтверждает или отклоняет участие.
10. Скидка считается только по подтверждённым контентам.

## Как тестировать перед хостом

```bat
.venv\Scripts\python.exe -m pytest -q
```

Проверьте вручную:

1. Начать фарм → игрок появляется в активных.
2. Завершить до 4 часов → в отчётах появляется запрос руководству назначить сумму.
3. Назначить сумму кнопкой.
4. Снова начать фарм в тот же день и довести суммарно до 4 часов → сумма должна стать автоматической.
5. Начать фарм → уйти на контент → подождать → вернуться → завершить фарм. Время контента не должно попасть в фарм.
6. После возврата отправить фото → в руководящий канал приходит карточка с фото и кнопками подтверждения.
7. Подтвердить контент → в личной статистике увеличивается число контентов и скидка.
8. Перезапустить бота во время фарма → активный таймер должен продолжиться.

## Дни без фарма

Если человек в конкретный день вообще не начинал фарм, бот показывает
`не фармил`. Запрос руководству на сумму не создаётся.

Ручная сумма требуется только после нажатия `Завершить фарм`, если чистое
время за день меньше настроенного порога.

## Slash-команды

Slash-команд в этой версии нет. На старте бот очищает старые глобальные и
серверные application-команды от предыдущих версий.


## Назначение суммы после завершения фарма

Если участник завершил день ниже порога, в `REPORT_CHANNEL_ID` появляется
отдельная карточка именно этого участника с кнопкой **«Назначить сумму»**.

Руководителю не нужно вводить Discord ID и дату. После нажатия кнопки
открывается одно поле — **сумма**. Пользователь и дата уже привязаны к карточке.

После назначения карточка помечается как обработанная.


# FARM Manager Bot v2.3 — новые функции

## Мой день
Кнопка **«Мой день»** показывает участнику только его сегодняшний статус:
чистое время фарма, сколько осталось до порога, подтверждённые контенты и
состояние дневного начисления.

## Карточка игрока
В панели руководства есть **«Карточка игрока»**. Игрок выбирается через
стандартный Discord User Select — никакие ID вручную не вводятся. Карточка
показывает каждый день недели, чистое время, начисления, контенты, скидку,
итоговый взнос и статус оплаты.

## Контроль забытой сессии
По умолчанию после 360 минут непрерывного фарма бот спрашивает игрока,
продолжает ли он фарм. Кнопки: **«Да, продолжаю»** и **«Завершить фарм»**.
Порог меняется в финансовых настройках. Значение `0` отключает напоминание.
Одно напоминание создаётся один раз на конкретный непрерывный фарм-сегмент.

## Контроль оплаты
Панель руководства: **Оплатили / На проверке / Не оплатили / Не рассчитано**.
Бот показывает конкретных игроков и суммы.

## Сравнение недель
Текущая неделя сравнивается с предыдущей по:
- чистому времени фарма;
- числу активных участников;
- среднему времени на активного участника;
- подтверждённым контентам;
- скидкам;
- рассчитанной сумме взносов.

## Автоматический еженедельный отчёт
По умолчанию отчёт отправляется в `REPORT_CHANNEL_ID` каждое воскресенье
в 23:00 по `TIMEZONE`. День и время меняются кнопками в панели руководства.
Автоотчёт можно включить/выключить и предварительно посмотреть.

Бот хранит факт отправки в БД, поэтому перезапуск не создаёт дубль.
Если бот был выключен в момент расписания, после запуска он отправит
последний пропущенный недельный отчёт один раз.

В отчёте:
- участники и активные фармеры;
- общее чистое время;
- контенты;
- сумма до скидок;
- скидки;
- рассчитано к оплате;
- оплатили / на проверке / не оплатили / не рассчитано;
- ТОП-10 по чистому фарму.

## Обновление с v2.2

Если хотите сохранить старую базу:
1. Остановите старого бота.
2. Скопируйте старый `.env` в папку v2.3.
3. Скопируйте старую папку `data` в v2.3.
4. Выполните установку зависимостей из `requirements.txt`.
5. Запустите `main.py`.

Новые таблицы и настройки создаются автоматически через `CREATE TABLE IF NOT EXISTS`
и `INSERT OR IGNORE`; удалять старую SQLite-базу для перехода на v2.3 не требуется.

Если нужна полностью чистая статистика, папку `data` переносить не нужно.


## v2.4 — фарм через полночь

Рабочий день фиксируется в момент первого нажатия **«Начать фарм»** и не меняется в 00:00.
Если игрок начал 23.08 в 23:00 и завершил 24.08 в 03:00, все 4 часа относятся к 23.08.
Контент не меняет рабочий день: время до и после контента остаётся в дне начала сессии, а само время контента не считается.
При переходе воскресенье → понедельник такая сессия остаётся в воскресенье и в старой неделе.
После окончательного **«Завершить фарм»** следующее новое нажатие **«Начать фарм»** создаёт новый рабочий день по фактической дате старта.

Если в момент недельного автоотчёта ещё идёт сессия, начатая в отчётной неделе, бот ждёт её завершения. Поэтому поздний воскресный фарм не потеряется из итогового отчёта.

### Недельный отчёт и ночные смены

Финальный недельный отчёт больше не фиксируется до реального окончания воскресенья.
Если после полуночи ещё идёт сессия с рабочим днём воскресенья (в том числе игрок
на контенте внутри этой сессии), бот ждёт её завершения и только после этого
отправляет полный отчёт за старую неделю.

При обновлении с v2.3 новая колонка `work_day` добавляется автоматически.
Если обновление произошло во время активного фарма или во время контента, бот
пытается восстановить исходный рабочий день из текущего/последнего фарм-сегмента.


## v2.5 — повторная смена ниже порога
Если сумма за рабочий день уже назначена, а игрок затем снова завершает фарм ниже порога, существующая карточка обновляется: показывает новое суммарное время и кнопки **«Оставить прежнюю сумму»** / **«Изменить сумму»**. При достижении порога ручная сумма автоматически заменяется автосуммой.
